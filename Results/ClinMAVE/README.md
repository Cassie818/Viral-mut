# Current ClinMAVE analysis files

This directory contains the current ClinMAVE files.

## Subdirectories

- `functional_effects/`: functional normal versus LoF/GoF analyses using CaLM
  with ESM-2 (650M) or ESM-1b (650M), used for Fig. 3.
- `cross_platform_context/`: matched DMS-CBGE dataset-pair modality-weight
  analyses used for Fig. 7 and related sensitivity checks.
- `supplementary_tables/`: ClinMAVE cohort counts, model-output descriptives,
  and full functional-class cross-validation results.
